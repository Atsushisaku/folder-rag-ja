# folder-rag-ja

フォルダ内の文書（Markdown / テキスト / PDF / Word）を対象に、ローカルの Ollama で動く RAG チャット。
外部 API には何も送りません。

- ハイブリッド検索：BM25（文字 2-gram）＋ 埋め込み検索（`bge-m3`）のスコアを重み付きで統合（BM25 の割合は `bm25_weight`）
- 回答が引用した資料を「参照」として 1 行で表示（ファイル名と見出し／PDF のページ）
- 生成中は「生成を停止」で止められる（途中までの回答は履歴に残る）
- 索引はプロジェクト内の `.rag_index/` に保存し、読み込むフォルダには何も書き込まない
- 2 回目以降は、追加・変更・削除されたファイルだけ索引を作り直す

## 必要なもの

- [uv](https://docs.astral.sh/uv/)（Python 本体も uv が用意するので、PC にインストール済みの Python のバージョンは問わない）
- [Ollama](https://ollama.com/) と、次の 2 つのモデル

```
ollama pull bge-m3
ollama pull qwen3:4b-instruct
```

## 使い方

```
uv sync
uv run streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。

### サイドバー

| 項目 | 内容 |
|---|---|
| 参照フォルダ | 読み込み済みのフォルダの一覧。クリックで切り替える（開いたときに変更分を自動で読み直す） |
| 参照… | フォルダ選択画面から、読み込むフォルダを追加する |
| 索引編集 | 選択中のフォルダの情報（パス・ファイル数・前回の更新結果）と、「索引を更新」「削除」（索引だけを削除し、元のファイルは消さない） |
| 中止 | 読み込み中に表示される。ここまでに読み込んだファイルは検索でき、続きは「索引を更新」で再開する |

設定を変える場合は `config.example.toml` を `config.toml` にコピーして編集します（`config.toml` は Git の管理対象外）。

### CLI（確認用）

```
uv run python -m rag_chat index <フォルダ>
uv run python -m rag_chat ask <フォルダ> "質問" [--no-llm]
```

## 対応形式と出典の表示

| 形式 | 出典の表示 |
|---|---|
| `.md` / `.markdown` | 見出しの階層（例：`経費精算マニュアル > 締め日と支払日`） |
| `.docx` | 見出しスタイル（見出し 1〜9）の階層 |
| `.pdf` | ページ番号（`p.3`） |
| `.txt` | ファイル名のみ |

画像の中の文字は読み取りません（OCR なし）。

## モデルについて

- 思考モード専用のモデル（例：`qwen3:4b` は Thinking 版）も使えますが、考える分だけ回答が大幅に遅くなります。CPU だけの PC では非思考モデル（`qwen3:4b-instruct` など）を推奨します。
- Streamlit は `.streamlit/config.toml` で `localhost` だけで待ち受ける設定にしてあります（LAN 側には公開しません）。
